# 奶蛙消消乐 · Naiwa Match3

Simplified match-3: swap neighbours, clear 3+, reach the score goal in 20 moves.

## Run

```bash
cd match3
npm install
npm run dev
npm test
npm run build
```

## How to play

- Tap two adjacent tiles to swap
- Matches of 3+ clear, gravity fills gaps, cascades score extra
- Reach 200 points within 20 moves
