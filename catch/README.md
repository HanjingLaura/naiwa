# 奶蛙接水果 · Naiwa Catch

Catch falling fruit with a yellow 奶蛙. Avoid bombs. Combo multiplies score.

## Run

```bash
cd catch
npm install
npm run dev      # local
npm test
npm run build    # dist/
```

## How to play

- Drag / ←→ to move 奶蛙 along the bottom
- Catch fruit (+10) and gems (+50); bombs cost a life
- 3 lives; combo ×1.5 at 5, ×2 at 10
