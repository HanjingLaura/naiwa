# 奶蛙飞飞 · Naiwa Fly

Flappy-style flyer: tap to flap through gaps in Kenney pipe columns.

## Run

```bash
cd fly
npm install
npm run dev
npm test
npm run build
```

## How to play

- Tap / Space to flap
- Pass between pipes to score
- Hit a pipe or the ground/ceiling and you’re done
