# 奶蛙打砖块 · Naiwa Breakout

Breakout with a 奶蛙 paddle and gem ball. Clear all bricks.

## Run

```bash
cd breakout
npm install
npm run dev
npm test
npm run build
```

## How to play

- Slide / ←→ to move the paddle; click or Space to launch
- Break all bricks; you have 3 balls
- Top rows take 2 hits
