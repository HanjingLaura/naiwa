# 奶蛙跳一跳 · Naiwa Jump

Charge-jump between platforms (WeChat jump spirit). Land near the centre for perfect bonus.

## Run

```bash
cd jump
npm install
npm run dev
npm test
npm run build
```

## How to play

- Hold to charge, release to jump toward the next platform
- Perfect centre landing = +2; normal = +1
- Miss the platform and it’s game over
